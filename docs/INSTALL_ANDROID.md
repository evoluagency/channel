# Instalação no Android

1. Instale Minecraft Bedrock original no celular.
2. Baixe o `Channel.mcaddon` pelo site.
3. Abra a pasta Downloads e toque no arquivo, escolhendo **Abrir com Minecraft** se o sistema solicitar.
4. Se o arquivo for `.bin`, use um gerenciador de arquivos para renomeá-lo para `Channel.mcaddon`. Confirme origem e integridade antes de abrir.
5. No Minecraft, crie um mundo **novo de teste** e ative `Channel (BP)` em Pacotes de Comportamento.
6. O jogador recebe a carteira e 100 moedas digitais.

O navegador **não consegue verificar com segurança** se o Minecraft está instalado. Se o Android não exibir Minecraft como aplicativo compatível, use a loja de aplicativos para instalá-lo e tente novamente.
