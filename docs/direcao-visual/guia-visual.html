Essência

Fantasia medieval de blocos, à noite

O mundo é de blocos e polígonos simples, como no jogo. A luz é de crepúsculo: céu violeta, pedra clara e lanternas quentes. O ouro aparece só no que importa: moldura do título, ação principal e item em foco. O violeta é a cor de agir. Cada herói tem a cor da sua força.

Fazer

  • Fundo escuro em todas as telas
  • Um único botão violeta por tela
  • Moldura dourada só no destaque
  • Separar o que está pronto do que vem depois

Evitar

  • Fundo claro ou branco
  • Ouro em todo painel
  • Texto sobre arte sem escurecer a imagem
  • Logos e nomes do Minecraft no jogo Valdora

Imagem e ícones

A arte-chave manda

Arte-chave

É a capa com o herói de escudo, o castelo de pedra clara e o mercado. Ela é concept art, não captura do jogo. Use sempre com uma camada escura por baixo do texto.

Título impresso

A arte original traz VALDORA escrito. No site essa área é escurecida, para o título real em texto não aparecer duplicado.

Ícones

Traço de 1,8 px, cantos redondos, grade de 24 px, cor do texto ou ouro. Sem ícones cheios e sem emoji.

Brasão

Coroa violeta de três pontas com losango dourado. Vai acima do nome VALDORA e no ícone do site.

Texto

Voz do reino, honesta com o jogador

  • Português do Brasil, frases curtas e verbos de ação: Construir, Governar, Expandir.
  • Tudo o que aparece como recurso diz se já está no jogo, em desenvolvimento ou planejado.
  • Nomes do jogo sempre com inicial maiúscula: Valeverde, Aurora, Estado, Temporada 1.
  • Aviso de risco diz o que se perde e como evitar: "Desinstalar apaga sua cidade".

extends RefCounted
const NOITE := Color("#0a0f22")
const NOITE_2 := Color("#10183a")
const VIOLETA := Color("#6a3fd4")
const VIOLETA_LUZ := Color("#b892ff")
const OURO := Color("#e2b865")
const PEDRA := Color("#ece6da")
const TEXTO_2 := Color("#a9a7c2")
const FORCAS := {"ferro": Color("#a7b1c2"), "nevoa": Color("#7cc3d1"),
                 "aurora": Color("#f2a7c8"), "brasa": Color("#ff8a4c")}

static func painel(foco := false) -> StyleBoxFlat:
    var s := StyleBoxFlat.new()
    s.bg_color = Color(NOITE_2, 0.94)
    s.border_color = OURO if foco else Color(VIOLETA_LUZ, 0.24)
    s.set_border_width_all(2 if foco else 1)
    s.set_corner_radius_all(18)
    s.set_content_margin_all(20)
    return s

static func botao_principal() -> StyleBoxFlat:
    var s := StyleBoxFlat.new()
    s.bg_color = VIOLETA
    s.border_color = OURO
    s.set_border_width_all(2)
    s.set_corner_radius_all(12)
    s.content_margin_left = 32
    s.content_margin_right = 32
    return s
